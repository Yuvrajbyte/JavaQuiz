# Project Statement

## Project Title
Java Quiz Application

## Problem Statement
I wanted to make a simple application that can help students practice their Java concepts. 
The application gives multiple-choice questions and shows the final score after completing the quiz.

## Scope
This project is mainly focused on basic Java programming concepts. It allows the user to answer 
questions, checks whether the answers are correct, calculates the score and displays the final result.

## Target Users
- Students learning Java
- Beginners who want to practice Java concepts

## High-Level Features
- Start a Java quiz
- Display multiple-choice questions
- Check the answers
- Calculate the score and percentage
- Display the final grade
- Show quiz instructions
- Handle invalid menu choices
