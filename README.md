# Java Quiz Application

## Overview
This is a simple console-based Java quiz application. I made this project to help
students practice basic Java programming concepts through multiple-choice questions.

## Features
- Start a quiz
- Multiple-choice questions
- Answer validation
- Score and percentage calculation
- Grade generation
- Quiz instructions
- Invalid input handling

## Technologies Used
- Java
- VS Code
- Java Scanner
- ArrayList

## How to Run
1. Open the project in VS Code.
2. Open the `src` folder.
3. Compile the Java files.
4. Run `Main.java`.
5. Select an option from the menu.

## Testing
The application was tested by:
- Starting the quiz
- Entering correct and incorrect answers
- Checking the final score and grade
- Entering an invalid menu option
