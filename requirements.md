# Requirements

## Functional Requirements

1. The user can start a quiz from the main menu.
2. The application displays multiple-choice Java questions.
3. The user can enter an answer for each question.
4. The application checks whether the answer is correct.
5. The application calculates the final score and percentage.
6. The application displays a grade based on the score.
7. The application provides instructions to the user.
8. The application handles invalid menu choices.

## Non-Functional Requirements

1. **Usability** - The application should be simple and easy to use.
2. **Performance** - Questions and results should be displayed quickly.
3. **Reliability** - The application should correctly calculate the user's score.
4. **Error Handling** - Invalid menu choices should be handled without crashing the application.
5. **Maintainability** - The code is divided into different classes to make it easier to understand and modify.
